# NEXUS VIDEO AI V4.2.1 — Cinematic Depth

This branch is isolated from `v4.2-cinematic` and starts at commit
`1c94b9d5b60fa9c9446893383e9eea1466f168a4`.

## Architecture
- `SceneLayer` stores an independently rendered RGBA plane with depth, position,
  scale, rotation, blur and camera weighting.
- `compose_scene_layers` composites ordered planes and applies depth-weighted camera offsets.
- Action overlays currently include a walking figure, handset vibration/lift, door leaf,
  moving cable, practical light, cast shadow and environmental particles.
- Layer manifests are written to `motion_report.json` for each scene.

## Known limitation — not final cinematic acceptance
The legacy V4.2 renderer still supplies a flattened scene plate as the background.
The new objects and atmosphere are independent overlays, but architectural elements
already baked into that plate cannot yet be separated into true foreground/midground/
background planes. Therefore this iteration does **not** claim complete scene-wide
parallax or independent animation of every original object. A proper next step is to
replace the legacy per-action drawing with authored scene assets/geometry that emit
separate background, midground, foreground and actor/prop layers before compositing.

## Validation
All 18 V4.2 tests remain in place; six new depth-compositor tests are added.
Thresholds remain: motion >= 1.25, diversity >= 7.0, duration error <= 0.15s,
A/V delta <= 0.15s. Acceptance render target is 45 seconds, H.264/AAC,
1080x1920 at 30 fps. The workflow compares the output against the V4.2 artifact
from run 43821467642 and uploads reports, six MP4-extracted frames and logs as a
GitHub Actions artifact. It is manual workflow_dispatch only.

No Make or Google Drive connection is performed by this branch workflow.
